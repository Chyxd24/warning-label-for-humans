The single-line safety warning label that should come printed on every human being.

> WARNING: Prolonged exposure to your own thoughts may cause you to believe you were right all along. Discontinue use if certainty persists.

138 characters. Funny first, plausible second.

## Run it

```sh
python3 main.py
```

Writes one line to `/output/entry.txt`. Stdlib only, no network, deterministic.
